# Datasets de Exploración Marciana (NASA MGS & Mars Odyssey)

Este directorio contiene los perfiles topográficos, térmicos y de inercia térmica oficiales para la caracterización de análogos marcianos:

## Contenido

### 1. Topografía (`topografia/`)
Modelos Digitales de Elevación (**MGS MOLA DEM**, Mars Orbiter Laser Altimeter):
- `Alba_Mons_Tharsis_volcan_MOLA_DEM.csv`: Transecto de 246.19 km en el megavolcán de Tharsis.
- `Jezero_Crater_Perseverance_MOLA_DEM.csv`: Delta fluvial fósil del río Neretva y lecho lacustre (Mars 2020).
- `Olympus Mons_marte.csv`: Perfil del mayor edificio volcánico del Sistema Solar (21.9 km altitud).
- `Valles Marineris_cañon gigante.csv`: Corte transversal del sistema de cañones tectónicos (hasta 7 km de profundidad).
- `Arcadia Planitia_planicie.csv`: Planicie septentrional con horizontes de hielo somero accesible.
- `Arsia Mons_topo_marte_crater.csv`: Volcán meridional con coladas piroclásticas y cuevas volcánicas.

### 2. Temperatura e Inercia Térmica (`temperatura/`)
Datos radiométricos de **MGS TES** y **Mars Odyssey THEMIS**:
- `Alba_Mons_temperatura_inercia_TES_THEMIS.csv`: Ciclo diurno con inercia térmica de 145 J m⁻² K⁻¹ s⁻⁰·⁵ (polvo volcánico).
- `Jezero_Crater_temperatura_inercia_TES_THEMIS.csv`: Ciclo diurno con inercia térmica de 320 J m⁻² K⁻¹ s⁻⁰·⁵ (arenas compactadas y carbonatos).
- `TES_Thermal_Inertia.tif`: Mapa raster georreferenciado de inercia térmica global de Marte.
